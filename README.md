# Retro Racer

브라우저에서 실행하는 유사 3D 아케이드 레이싱 게임입니다. 맵을 고른 뒤 라이벌 다섯 명과 함께 달리고, 제한 시간 안에 체크포인트를 통과하면서 결승점까지 1위를 노립니다.

## 바로 하기

- 공개 사이트: https://geonwoologibros.github.io/retro-racer/ (누구나 로그인 없이 같이 하기를 쓸 수 있습니다)
- claude.ai 링크: https://claude.ai/artifact/3Z8M66LLC7xUnhqm9aLUjD (같이 하기는 claude.ai에 로그인한 사람만 쓸 수 있습니다)

## 실행 방법

    npm install
    npm run dev

터미널에 출력되는 주소를 브라우저에서 엽니다.

## 조작

| 키 | 동작 |
|---|---|
| ← / → (A / D) | 좌우 조향. 타이틀 화면에서는 맵 선택 |
| ↑ (W) | 가속 |
| ↓ (S) | 브레이크 |
| Shift | 드리프트 (조향 키와 함께) |
| Space | 부스터 사용 |
| Enter | 시작, 다시 시작 |
| Esc | 결과 화면에서 맵 선택으로 돌아가기 |
| M | 소리 켜기·끄기 |

## 맵

| 맵 | 난이도 | 구간 테마 |
|---|---|---|
| 선셋 코스트 | ★★★ | 해변 → 사막 → 숲 → 야간 도시 → 새벽 |
| 사쿠라 로드 | ★ | 벚꽃길 → 대나무 숲 → 사찰 → 등불 거리 → 달밤 |
| 스노우 패스 | ★★ | 눈 덮인 숲 → 빙판 호수 → 설산 → 눈보라 → 오로라 |
| 캐니언 러시 | ★★★ | 협곡 입구 → 붉은 절벽 → 강바닥 → 고원 → 석양 |
| 네온 시티 | ★★★★ | 도심 → 항구 → 터널 → 고가도로 → 네온 거리 |
| 문 베이스 | ★★★★ | 달 기지 → 크레이터 → 태양 전지 평원 → 운석 지대 → 지구돋이 |
| 볼케이노 | ★★★★★ | 정글 → 화산재 평원 → 용암 지대 → 분화구 → 화산 정상 |
| 볼타 러너 | ★★★ | 협곡 어귀 → 유적 지대 → 흙먼지 평원 → 협곡 다리 → 별빛 하늘길 |

맵은 커브의 세기와 빈도, 언덕, 지나는 지형이 다르고, 길이와 시간 제한은 모두 같습니다. 같은 맵이라도 달릴 때마다 커브의 순서와 좌우, 길가 사물 배치가 달라집니다. 지형이 이어지는 순서는 그대로입니다.

볼타 러너는 차 대신 토끼 귀 우주인 캐릭터가 달리는 맵입니다. 라이벌도 같은 캐릭터로 달립니다. 부스터나 터보를 쓰면 제트팩을 켜고, 드리프트하면 웅크린 채 흙먼지를 일으키며, 부딪히면 멈칫합니다. 체크포인트는 유적 아치입니다.

## 지형

한 구간 안에서도 도로가 계속 바뀝니다.

| 지형 | 모습 | 주행 |
|---|---|---|
| 포장도로 | 2~4차선. 차선이 많을수록 넓습니다. | 기본 |
| 흙길 | 차선 없는 흙길과 바퀴 자국 | 커브에서 더 밀리고 최고 속도가 95%로 낮아집니다. |
| 다리 | 좁은 나무 다리. 양옆은 강(화산에서는 용암)입니다. | 밖으로 벗어나면 떨어집니다. |
| 여울 | 얕은 강을 그대로 건넙니다. | 최고 속도가 75%로 낮아집니다. |
| 빙판 | 얼음길 | 커브에서 훨씬 많이 밀립니다. |
| 우주 | 별 사이에 뜬 빛나는 길 | 최고 속도가 110%로 높아지고, 밖으로 벗어나면 떨어집니다. |

다리나 우주의 길에서 떨어지면 속도가 40%로 줄고 길 가운데로 돌아옵니다.

## 규칙

### 경주
- 라이벌 다섯 명이 앞에 서고, 플레이어는 맨 뒤(6위)에서 출발합니다. 화면 왼쪽 위에 지금 순위가 표시됩니다.
- 라이벌은 맵 난이도가 높을수록 빠르고, 급커브에서는 속도를 줄이며, 가끔 부스터를 씁니다. 너무 멀리 뒤처지거나 앞서면 조금 따라잡거나 기다립니다.
- 라이벌의 뒤를 들이받으면 조금 느려지면서 옆으로 튕겨 나갑니다.
- 60초로 시작하며, 체크포인트를 통과할 때마다 30초가 추가됩니다. 시간이 0이 되면 가속할 수 없고, 멈추면 경주가 끝납니다.

### 드리프트와 부스터
- 속도가 최고 속도의 절반 이상일 때 Shift를 누른 채 조향하면 드리프트가 됩니다. 조향이 강해지고 커브에서 덜 밀리지만 최고 속도가 85%로 낮아집니다. 급커브는 감속하거나 드리프트해야 돌 수 있습니다.
- 드리프트를 오래 유지할수록 뒷바퀴 불꽃이 파랑(0.5초), 주황(1.1초), 보라(1.8초)로 바뀝니다. 드리프트를 끝내는 순간 단계에 맞는 터보(0.3~0.8초)가 붙고, 속도가 바로 최고 속도로 돌아옵니다.
- 드리프트를 끝낸 뒤 0.3초 안에 반대 방향키를 누르면 순간 부스터로 터보가 0.5초 더 붙습니다.
- 드리프트하는 동안, 그리고 터보를 받거나 연속 보너스를 쌓을 때 부스터 게이지가 찹니다. 게이지가 가득 차면 부스터 한 칸이 되고, 부스터는 두 칸까지 모입니다.
- Space를 누르면 부스터 한 칸을 써서 1.6초 동안 최고 속도의 135%까지 달립니다.

### 연속 보너스와 연출
- 터보, 순간 부스터, 라이벌 추월을 3초 안에 이어서 하면 연속 보너스가 쌓이고, 쌓일수록 게이지를 더 채워 줍니다. 화면에는 NICE, GREAT, EXCELLENT, PERFECT 순서로 칭찬이 뜨고, 부딪히면 연속 보너스가 끊깁니다.
- 부스터를 켤 때는 화면이 번쩍이고, 터보가 붙을 때는 화면 가장자리가 빛납니다. 부딪히면 화면이 잠깐 멈추고 크게 흔들리며 차체가 휘청입니다.
- 부스터를 쓰는 동안에는 카메라가 뒤로 물러나고 화각이 넓어지며, 속도선과 화면 흔들림이 더해집니다. 평소에도 속도가 오를수록 화각이 조금씩 넓어집니다.
- 드리프트하는 동안에는 뒷바퀴 아래로 타이어 자국이 남습니다.

### 충돌과 기록
- 도로 밖으로 나가면 속도가 줄어듭니다. 길가 사물에 부딪히면 속도가 절반으로 줄어듭니다. 코스에는 일반 차량이나 장애물이 없습니다.
- 화면 오른쪽 아래의 미니맵에 코스 전체 모양, 체크포인트, 라이벌과 내 위치가 표시됩니다.
- 완주하면 순위와 클리어 타임이 표시됩니다. 완주 시간과 도달 거리의 최고 기록은 맵별로 브라우저에 저장됩니다.

## 같이 하기

타이틀 화면 오른쪽 위의 '같이 하기'를 누르면 방을 만들거나 방 코드로 참가할 수 있습니다.

- 방을 만들면 다섯 글자 방 코드와 초대 링크가 나옵니다. 초대 링크로 들어온 사람은 방 코드가 채워진 참가 창을 바로 봅니다. 열린 방 목록에서 골라 들어갈 수도 있습니다.
- 방을 만든 사람이 방장입니다. 방장이 맵을 고르고 '출발하기'를 누르면 모두 같은 코스에서 3초 카운트다운 뒤에 출발합니다. 방장이 나가면 가장 먼저 들어온 사람이 방장이 됩니다.
- 함께 달릴 때는 AI 라이벌이 없고, 다른 사람의 차는 부딪히지 않는 반투명한 모습으로 보입니다. 순위는 완주 기록, 달린 거리 순서로 정합니다.
- 완주하거나 시간이 끝나면 오른쪽에 순위표가 나옵니다. 방장은 '다시 출발하기'나 '대기실로'를 고를 수 있습니다.
- 방장이 출발선 근처에 있을 때 들어온 사람은 그 경주에 함께 출발하고, 이미 멀리 간 경주에 들어온 사람은 다음 경주를 기다립니다. 달리는 중에 Esc를 누르면 방을 나갑니다.
- 미니맵에는 함께 달리는 사람이 각자의 차 색과 같은 색 점과 이름으로 실시간 표시됩니다.
- claude.ai에 게시한 링크에서는 claude.ai의 실시간 방 기능을 씁니다. 이때는 같은 조직 사람이나 링크에 초대받은 사람이 claude.ai에 로그인한 상태여야 합니다.
- claude.ai 계정이 없는 사람과 하려면 공개 사이트에서 하면 됩니다. `npm run dev`로 실행한 화면에서는 혼자 하기만 됩니다.

### 공개 사이트 (GitHub Pages)

`main` 브랜치에 올리면 GitHub Actions가 테스트를 돌리고 `npm run build:web`으로 공개 사이트용 파일을 만들어 GitHub Pages에 배포합니다(`.github/workflows/pages.yml`).

공개 사이트에서는 브라우저끼리 직접 연결(WebRTC)합니다. 처음 서로를 찾을 때만 PeerJS의 무료 공개 서버를 쓰고, 별도 서버나 계정은 필요 없습니다(`.env.web`의 `VITE_NET=p2p`).

- 방 코드로 정한 이름표를 먼저 차지한 브라우저가 중계를 맡고, 나머지는 그 브라우저에 연결합니다. 중계하던 사람이 나가면 남은 사람 중 한 명이 이어받습니다.
- 서버가 방 목록을 모아 두지 않아서 열린 방 목록은 없습니다. 방 코드나 초대 링크로 들어옵니다.
- 회사나 학교처럼 막힌 네트워크에서는 연결되지 않을 수 있습니다.

### Supabase Realtime으로 바꾸기

P2P 대신 Supabase Realtime을 쓰려면 `.env.web`에서 `VITE_NET` 줄을 지우고, `.env.web.example`처럼 Supabase 프로젝트 주소와 공개용 키를 넣습니다. Supabase 무료 요금제는 Presence를 한 사람당 30초에 5번까지만 바꿀 수 있고, 메시지가 프로젝트 전체에서 초당 100개(받는 사람마다 하나씩 셈)로 제한됩니다. 그래서 Presence는 방에 들어왔다는 것만 알리고, 각자의 상태는 Broadcast로 보냅니다. 보내는 간격은 2~3명이면 0.2초이고, 인원이 늘면 메시지 수가 예산 안에 들도록 길어집니다.

## 개발

    npm test        # 단위 테스트
    npm run build   # 타입 검사와 빌드

게임 규칙은 `src/game/`에, 화면 그리기는 `src/render/`에 있습니다. 속도·시간과 같은 조정값은 `src/game/constants.ts`에, 라이벌의 움직임은 `src/game/rivals.ts`에, 맵별 코스·테마·지형은 `src/game/maps.ts`에, 함께 달리기는 `src/multiplayer.ts`(방 화면과 동기화)와 `src/game/multi.ts`(규칙)에, 지형별 폭과 주행 규칙은 `src/game/terrain.ts`에 모여 있습니다.

## 에셋 출처

`src/assets/codmos/`의 그림은 코드모스 에셋 라이브러리에 있는 'AI체험 동작인식 #AI21' 콘텐츠의 mission4 에셋(`cms/motion-recognition/assets/mission4/`)을 게임에 맞게 줄인 것입니다. 원본의 사용 조건은 해당 콘텐츠의 라이선스를 따릅니다.
